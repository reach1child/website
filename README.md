# Reach One Child Foundation Website

Website repository for Reach One Child Foundation (R1CF).

## Brand
- Navy: `#041968`
- Red: `#EE3135`
- White: `#FFFFFF`

## Project status
The repository is being prepared for the website build. The homepage design direction is a modern, professional, photography-led nonprofit website.

## Image library
Upload approved website images into `public/images/`. See [the image upload guide](public/images/README.md) for the folder map, file naming, and image guidance.

## Planned application structure
As the website is implemented, the codebase will be organized around:
- `src/app/` — pages, layouts, and route-specific metadata
- `src/components/` — reusable navigation, hero, programme cards, impact strip, stories, partner and footer components
- `src/lib/` — shared utilities and configuration
- `public/images/` — approved image assets served by the website
- `public/icons/` — favicon and other static brand icons
- `docs/` — project notes and content guidance

The framework and CMS will be selected before application code is scaffolded.

## Important
Only upload images that R1CF is authorized to publish. Obtain appropriate consent for identifiable children, and do not upload private records, personal contact lists, or confidential documents to this public repository.
