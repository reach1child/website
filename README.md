# Reach One Child Foundation website

A responsive Next.js website for Reach One Child Foundation (R1CF), Zambia.

## Brand
- Navy: #041968
- Red: #EE3135
- White: #FFFFFF

## Stack
- Next.js App Router
- React 19
- TypeScript
- Custom responsive CSS

## Run locally
```bash
npm install
npm run dev
```

## Images and content
The homepage uses image assets stored in `public/images/`. Programme descriptions and impact figures are based on the R1CF 2026 organisational profile. Confirm current figures before future updates and obtain appropriate consent before publishing identifiable children or personal stories.

## Content management
This first release is a static, code-managed homepage. A CMS can be integrated in a later phase so authorised staff can update pages, programme content, news and images without editing code.
