# R1CF Website Image Library

Upload website-ready, approved images into the folders below. These folders are committed to GitHub so the website can use the images directly.

## Folders

| Folder | What belongs here |
| --- | --- |
| `branding/` | Foundation logo, logo variations, approved brand graphics |
| `hero/` | Homepage banner and wide feature photographs |
| `programmes/` | Education Fund, #1Friend1Box, Read to Lead, Nutrition Campaign |
| `stories/` | Approved photographs for beneficiary stories and impact features |
| `partners/` | Partner and supporter logos |
| `team/` | Approved board, staff, and volunteer portraits |

## File naming
Use lowercase names with hyphens. Examples:
- `r1cf-logo-full.png`
- `homepage-hero-classroom.webp`
- `jack-lumpa-education-fund-activity-01.webp`
- `read-to-lead-session-01.webp`
- `partner-name-logo.svg`

For repeated photos, add a sequence number such as `activity-01.webp`, `activity-02.webp`.

## Image recommendations
- Prefer WebP or optimized JPEG for photographs.
- Use PNG or SVG for logos when available; keep transparent backgrounds for logos that need them.
- Homepage hero: ideally landscape, around 2000 px wide or larger.
- Programme and story photos: landscape images around 1200 px wide work well.
- Avoid uploading duplicate, blurry, watermarked, or heavily compressed images.
- Keep original high-resolution copies backed up separately.

## Before uploading
- Confirm R1CF has permission to publish each image.
- Obtain appropriate parent/guardian consent before publishing identifiable children.
- Do not upload confidential case files, school records, medical information, identity documents, or private contact details.
- Do not put names or other identifying details of children in filenames.

## How to upload
1. Open the folder in GitHub.
2. Choose **Add file → Upload files**.
3. Drag the image files into the upload area.
4. Commit the upload to the `main` branch.
5. Tell me the filenames or folder you uploaded, and I can use them in the website.

You can create additional subfolders as the image library grows. Keep each image in the most relevant category.
